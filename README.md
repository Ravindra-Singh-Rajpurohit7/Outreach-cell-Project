# IIT Roorkee Outreach Cell Information Portal

A centralized information platform developed for the IIT Roorkee Outreach Cell to help students stay updated with important campus announcements, events, opportunities, and notices in one place.

The goal of the platform was to reduce information gaps and ensure that students do not miss important updates happening across the campus.

## Author

**Ravindra Singh Rajpurohit**

## Problem Statement

Students often receive information through multiple channels such as WhatsApp groups, emails, and social media, making it easy to miss important announcements.

This platform was built to provide a single, organized location where students can access the latest campus-related updates.

## Features

- Centralized announcement platform
- Detailed post pages for complete information
- Clean and responsive user interface
- Fast navigation using React Router
- Mobile-friendly design
- Organized content display for better accessibility

## Tech Stack

### Frontend
- React.js
- React Router DOM
- Tailwind CSS
- JavaScript
